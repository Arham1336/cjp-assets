Admin Login

Enter your Admin Key. It is never shown in the page after login.

User Management

All members, newest first. Search by ID, username or name. Edit CJP, USDT or permanent VIP level (only changed fields are saved).

Deposits

Verify USDT deposits before crediting the member. Shows name, username and Telegram ID.

Withdrawals

Processing requests waiting for payout. Shows name, username and exact amount to send.

CJP Coin Withdrawals

Send the coins from your Tonkeeper wallet to the address shown, then mark it sent with the transaction hash.

Payout Proofs

Completed withdrawals shown on the public /payouts page. Remove any entry you don't want publicly visible — this only hides it from that page, it does not affect the member's balance or records.

Task Controls

Turn earning tasks on or off. Settings are stored persistently.

Monthly Top Referrers

Live top 10 (VIP referrals only) for this month and the winners already paid.

Database Status

Since v2.0 all data lives in relational PostgreSQL tables. Your old data was imported automatically on the first start. This shows the migration status and the current table sizes.

Copy Database to a New Provider (e.g. Neon)

Paste the new Postgres connection string below and click Copy. This only copies the data — it does NOT switch the app to use it. After copying, update DATABASE_URL in Render's environment variables to this same string and redeploy to actually switch over.

Backup

Downloads a full JSON export of all users, deposits, withdrawals and balances — useful as a manual reference copy.
